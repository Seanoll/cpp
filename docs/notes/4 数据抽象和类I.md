## 函数重载

在开发中，需要的函数功能类似，但参数数量或类型不同，C++可以声明同样名称的一组函数，但参数类型不同。

函数签名：编译器将函数名、参数数量、参数类型编译为唯一的内部变量名。但是不包含返回类型。例如Swap_int_int和Swap_float_float是不同的函数签名。

```cpp
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int main() {
    cout << add(1, 2) << endl;       // 调用 int 版本
    cout << add(1.5, 2.5) << endl;   // 调用 double 版本
}
```

## 默认参数

半缺省参数

```cpp
void Func(int a, int b = 2, int c = 3)
{//调用此函数时必须给a传参数
	cout << a << b << c << endl;
}
//规定只能从右往左缺省，不能从左往右或者间隔缺省。
```

全缺省参数

```cpp
void func(int n=1, float b=1.2, char c='@'){
    cout<<n<<", "<<b<<", "<<c<<endl;
}
int main(){
    func(); //func(1,1.2,'@')
    func(10); //func(10,1.2,'@')
    func(20, 9.8); //func(20,9.8,'@')
    func(30, 3.5, '#'); //func(30,3.5,'#')
    return 0;
}
```

默认参数只能定义在参数右边，例如：`void func(int n,float b=1.2,char c='@')`是正确的，但是`void func(int n=1,float b,char c)`是错误的。

## 访问控制

私有成员变量只有类和友元函数可以访问。

```cpp
class Account {
private:
    int balance = 0;  // 类外不能直接访问

public:
    void deposit(int amount) {
        balance += amount;  // 类的成员函数可以访问
    }

    int getBalance() const {
        return balance;
    }
};

int main() {
    Account account;
    account.deposit(100);
    cout << account.getBalance() << endl;  // 输出 100
}
```

## 构造函数

类的构造函数是类的一种特殊的成员函数，每次创建类的新对象时完成初始化等逻辑。构造函数的名称与类的名称是完全相同的，并且不会返回任何类型，也不会返回void，在定义时前面不能写返回类型。如果用户没有自定义构造函数，则编译会自动生成一个默认构造函数。构造函数不能被直接调用。

构造函数可以有参数，有参数的时候初始化就需要传初始值。

```cpp
class Line {
public:
    Line(double length) : length(length) {}

private:
    double length;
};

int main() {
    Line line(10.0);  // 创建对象时调用构造函数，初始长度为 10.0
    Line line1;    // 错误：没有提供无参构造函数
}
```

## 析构函数

析构函数是类的一类特殊成员函数，它会在对象被释放前执行。析构函数的名称与类的名称是完全相同的，只是在前面加了个波浪号（~）作为前缀，它不会返回任何值，也不能带有任何参数。析构函数不能被直接调用。它有利于跳出程序前释放资源。

```cpp
class Message {
public:
    ~Message() {
        cout << "对象即将销毁" << endl;
    }
};

int main() {
    Message message;
}  // 离开作用域时自动调用析构函数
```

## this指针

this会指向当前对象。this->成员。

友元函数没有类的指针，因为友元不是类的成员，只有动态成员函数才有this指针。static成员不能使用this，静态成员是所有对象共用的，应使用类名::成员，当成员函数参数与成员数据重名时，必须用this访问成员数据。

```cpp
class Student {
public:
    void setAge(int age) {
        this->age = age;  // 左边是当前对象的成员，右边是参数
    }

    int getAge() const {
        return age;
    }

private:
    int age = 0;
};
```

## 类的静态成员

static成员是类的组成部分但不是任何对象的组成部分，通过在成员声明前加上保留字static将成员设为static。

静态数据成员具有静态（全局）生存期，是类的所有对象共享的存储空间，静态数据成员不是通过构造函数初始化，而是必须在类的定义体外部再定义一次，且恰好一次。通常是在类的实现文件中再声明一次，而且此时不能再用static修饰。静态成员函数不能直接访问类的非静态成员，只能访问类的静态数据或函数成员。

```cpp
class Counter {
public:
    Counter() {
        ++count;
    }

    static int getCount() {
        return count;
    }

private:
    static int count;  // 所有 Counter 对象共享
};

int Counter::count = 0;  // 在类外定义并初始化一次

int main() {
    Counter first;
    Counter second;
    cout << Counter::getCount() << endl;  // 输出 2
}
```

在 C++ 中，可以在函数声明时为参数提供一个默认值 。这样在函数调用时，如果没有提供函数参数值，则使用默认值。 

出现错误`error: default argument given for parameter`的原因是函数声明与函数定义中均指定了默认值。解决办法：仅在声明和定义其中一个中指定默认值。

```cpp
void printNumber(int number = 10);  // 默认值写在声明中

void printNumber(int number) {      // 定义中不重复写默认值
    cout << number << endl;
}

int main() {
    printNumber();     // 使用默认值 10
    printNumber(25);   // 使用传入的值 25
}
```
