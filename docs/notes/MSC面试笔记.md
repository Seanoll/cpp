## 宏定义

宏定义通过#define指令将一个标识符（宏名）与一个字符串、常量或表达式关联。在编译前，预处理器会将程序中出现的宏名替换为宏定义的内容，这一过程称为宏展开（宏替换）

> C++不建议使用宏，但要能看懂宏

```cpp
#define 标识符 替换表达式
```

在使用简单宏定义时，当字符串中不只一个符号时，加上括号表现出优先级，如果是带参数的宏定义，则要给宏体中的每个参数加上括号，并在整个宏体上再加一个括号。

```cpp
#define Conn(x,y) x##y
#define ToChar(x) #@x
#define ToString(x) #x
```

## 函数指针

与数组类似，函数的名称就代表了它的地址，我们可以使用指针来指向这个地址

```cpp
返回类型 (*函数指针名称)(参数列表)
```

例如
```cpp
double (*ptr)(double, double) = multiply
```
