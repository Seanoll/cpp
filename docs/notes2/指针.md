## 指针的基本概念

- **地址**：标识数据在内存中的位置。可以把普通内存理解成一串按字节编号的位置。
- **指针变量**：保存地址的变量；指针类型说明通过这个地址要访问什么类型的数据。
- `int *p` 表示 `p` 可以指向 `int`，`double *q` 表示 `q` 可以指向 `double`。

```c
int a = 10;
int *p = &a; // p 保存 a 的地址，称为“p 指向 a”
```

### 定义指针变量

```c
int *p = NULL;
char *s = NULL;

int *p1, p2;   // p1 是指针，p2 是 int
int *p3, *p4;  // 两个都是指针
```

- 声明中的 `*` 说明对应变量是指针，**不会自动作用于逗号后的其他变量**。
- 声明指针不会自动创建它指向的对象。
- 指针变量也可用 `extern`、`static`、`auto`、`register` 等存储类说明符修饰；它们不改变所指数据类型。

## 取地址与解引用

| 写法 | 含义 |
| --- | --- |
| `&a` | 取变量 `a` 的地址 |
| `*p` | 解引用：访问该地址处的对象（非第一次出现时的含义） |

```c
int a = 10;
int *p = &a;

*p = 20;     // 通过指针修改 a
int b = *p;  // 通过指针读取 a，b 为 20
```

- `*p` 与 `a` 指的是**同一个对象**，不是复制出来的新变量。
- 对有效的对象指针，`&*p` 和`*&a` 是什么意思？
- `&` 要用于可取地址的对象，例如变量、数组元素；不能写 `&10`、`&(a + 1)`。

### 输出地址与 sizeof

```c
int a = 10;
int *p = &a;
printf("%p\n", p);  // p 保存的地址
printf("%p\n", &p); // p 自己的地址
printf("%zu\n", sizeof(p));  // 指针变量的大小
printf("%zu\n", sizeof(*p)); // 所指类型 int 的大小
```

- 指针本身也占内存，`p` 和 `&p` 表示的不是同一个含义。
- 常见 32 位平台指针占 4 字节，常见 64 位平台占 8 字节。
- `void*`可指向任意类型的数据，是 C 中的“通用指针”。

## NULL、野指针与对象生存期

### 空指针

- `NULL` 是标准头文件提供的**空指针常量**。
- 指针取空值表示当前不指向任何对象或函数，不能解引用。
- 没有可用地址时应先初始化为 `NULL`。

```c
int *p = NULL;
if (p != NULL) { // 也可以写 if (p)
    printf("%d\n", *p);
}
```

### 野指针

| 问题 | 原因 | 正确做法 |
| --- | --- | --- |
| 未初始化指针 | 保存的地址不确定 | 初始化为有效地址或 `NULL` |
| 悬垂指针 | 所指对象已被释放，或已离开生存期 | 不再访问失效对象，及时清理指针 |
| 越界访问 | 移出合法范围，或解引用尾后位置 | 检查边界 |

```c
int *bad(void) {
    int x = 1;
    return &x; // 返回后 x 已失效
}

int *p; // 错：未初始化，p 是野指针
printf("%d\n", *p); // 未定义行为，可能段错误

int *q = NULL;
printf("%d\n", *q); // 错：解引用空指针，通常段错误

int *r = malloc(sizeof(int));
free(r);
printf("%d\n", *r); // 错：free 后未置 NULL，r 是野指针
```

- 解引用无效指针属于**未定义行为**，可能崩溃，也可能出现貌似正常的错误结果。
- 防御性编程三条守则：初始化、判空、释放后置 NULL。

## 指针与数组

### 数组名的转换

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a; // 大多数表达式中，a 转换为 &a[0]
```

- **数组不是指针变量**。数组名只是在大多数表达式中“退化”为指向首元素的指针。
- 当 `p == a` 时，`p[i]` 与 `a[i]` 访问同一个元素。
- 下标运算本质上是“移动指针，再解引用”：

```c
a[2];       // 第三个元素
*(a + 2);   // 等价
p[2];       // 此时也等价
2[a];       // 语法上等价，但不建议这样写
```

- 定义后可以让 `p = a`、`p++`，但不能让 `a = p`、`a++`。

### 不退化的常见情况：sizeof 与 &

```c
int a[5];
int *p = a;
int (*pa)[5] = &a; // pa 指向整个“含 5 个 int 的数组”
sizeof(a) // a指的是整个数组
```

| 表达式 | 含义或类型 | 加 1 的步长 |
| --- | --- | --- |
| `a`（转换后）或 `&a[0]` | 指向首个 `int`，类型为 `int *` | 一个 `int` |
| `&a` | 指向整个数组，类型为 `int (*)[5]` | 整个数组，即 5 个 `int` |
| `sizeof(a)` | 整个数组大小，即 `5 * sizeof(int)` | 不适用 |
| `sizeof(p)` | 指针自身的大小 | 不适用 |

## 指针的算术与比较

### 算术运算

设 `p` 指向某个数组内的元素，`i` 是整数：

| 写法 | 含义 |
| --- | --- |
| `p + i` | 向后移动 `i` 个元素 |
| `p - i` | 向前移动 `i` 个元素 |
| `p++`、`++p` | 指向下一个元素 |
| `p--`、`--p` | 指向前一个元素 |
| `q - p` | 同一数组中，两个位置相隔的元素个数 |

- 移动按**元素**计算，不是按字节：`int *` 加 1 移动 `sizeof(int)` 字节。
- 指针只能在同一数组内移动，或者指向**最后一个元素之后的位置**，称为“尾后指针”，但不能解引用它。
- 两个指针不能相加，也不能对指针做乘、除运算。
- 指针相减要求指向同一数组内的元素。
- `p[-1]` 不一定越界：如果 `p = a + 1`，则 `p[-1]` 是 `a[0]`；是否越界取决于最终访问的位置。

### 比较运算

- `p == q`、`p != q`：判断指针是否相等，常用于判空或判断是否到达结束位置。
- `<`、`<=`、`>`、`>=`：数组遍历时用于比较**同一数组位置**的先后。

## 指针数组、数组指针与二级指针

### 指针数组：数组中存放指针

```c
int a[3] = {1, 2, 3};
int *p[3] = {&a[0], &a[1], &a[2]};
printf("%d\n", *p[1]); // 2
```

- `int *p[3]`：`p` 先与 `[]` 结合（`[]` 的优先级高于一元 `*`），所以它是一个有 3 个元素的数组，每个元素都是 `int *`。
- `p[i]` 是指针，`*p[i]` 是这个指针所指的整数。

### 数组指针：指向一整行数组

```c
int m[2][3] = {{1, 2, 3}, {4, 5, 6}};
int (*p)[3] = m;
printf("%d\n", p[1][2]); // 6
```

- `int (*p)[3]`：`p` 先与括号里的 `*` 结合，所以它是指针，指向“含 3 个 `int` 的数组”。
- `p[i]` 表示第 `i` 行，`p[i][j]` 等价于 `*(*(p + i) + j)`。
- 二维数组 `m` 的首元素是**一行数组**，因此退化后是 `int (*)[3]`，不是 `int **`。

### 二级指针：指向指针变量

```c
int x = 10;
int *p = &x;
int **pp = &p;

**pp = 20; // 先用 *pp 找到 p，再用 **pp 访问 x
```

| 表达式 | 含义 |
| --- | --- |
| `pp` | 指针变量 `p` 的地址 |
| `*pp` | 指针 `p` 保存的地址，即 `&x` |
| `**pp` | 原变量 `x` |

### 三者如何配合访问二维数据

```c
int m[2][3] = {{1, 2, 3}, {4, 5, 6}};
int (*p)[3] = m;          // 数组指针：直接按固定行宽访问 m
int *rows[2] = {m[0], m[1]}; // 指针数组：额外保存每一行首元素的地址
int **pp = rows;          // 二级指针：指向 rows 的首个指针元素

printf("%d %d %d\n", p[1][2], rows[1][2], pp[1][2]); // 都是 6
```

- `p` 移动时按整行计算；`pp` 先找到行指针，再通过该指针访问整数。
- 不能直接写 `int **pp = m;`，二者所需的存储结构和类型不同。

## 指针与函数参数

### C 只有值传递

- 普通形参是实参值的副本，在函数里修改形参，不会改变调用者的变量。
- 想修改调用者的对象，就传它的**地址**，函数通过指针间接修改。
- 常说的“按地址传递”，实际上传递的仍然是**地址值的副本**。

```c
void swap(int *px, int *py) {
    int t = *px;
    *px = *py;
    *py = t;
}

// 调用：int a = 3, b = 5; swap(&a, &b);
```

- 如果只写 `void swap(int x, int y)` 并交换 `x、y`，交换的只是副本。

### 输出参数：一次得到多个结果

```c
void divmod(int a, int b, int *q, int *r) {
    *q = a / b;
    *r = a % b;
}

// 调用：int q, r; divmod(17, 5, &q, &r); // q = 3，r = 2
```

- 调用者提供保存结果的变量，函数用指针写回。
- 使用前要保证 `b != 0`，除法结果在 `int` 范围内，且 `q、r` 指向有效对象。

### 数组作为函数参数

```c
void clear(int a[], int n) { // 形参中的 int a[] 等价于 int *a
    for (int i = 0; i < n; i++) {
        a[i] = 0;
    }
}

// 调用：int a[5]; clear(a, 5);
```

- 函数没有收到整个数组的副本，而是收到指向首元素的指针，可以修改原数组的元素。
- 如果在函数内用 `sizeof(a)` ，结果是指针大小，想知道数组长度应单独传入。
- 二维数组形参需知道列数，例如 `void f(int a[][3], int rows)`，等价于 `void f(int (*a)[3], int rows)`。

## 函数指针

- **函数指针**保存函数地址，可以间接调用函数。
- 所指函数的返回类型、参数类型和数量应与函数指针类型匹配。

```c
int max_value(int a, int b) {
    return a > b ? a : b;
}

int (*choose)(int, int) = max_value;
// 也可以写 = &max_value;

// 调用：int x = choose(3, 5);     // 5
// 或者：int y = (*choose)(3, 5); // 5
```

- 格式：`返回类型 (*指针名)(参数类型列表)`。
- `int (*p)(int, int)` 是函数指针；`int *p(int, int)` 则声明一个返回 `int *` 的函数。
- 函数指针不能做指针加减、自增、自减或下标运算。

## 回调函数

- 把函数指针作为参数传入，让被调用函数在需要时调用它，这个传入的函数称为**回调函数**。
- 同一个处理流程可以通过不同回调采用不同规则，例如选最大值或最小值。

```c
int select_all(const int *a, int n, int (*select)(int, int)) {
    int result = a[0];
    for (int i = 1; i < n; i++) {
        result = select(result, a[i]);
    }
    return result;
}
```

### qsort：通过回调决定排序规则

`<stdlib.h>` 提供标准排序函数：

```c
void qsort(void *base, size_t nmemb, size_t size,
           int (*compar)(const void *, const void *));
```

| 参数 | 含义 |
| --- | --- |
| `base` | 数组起始地址 |
| `nmemb` | 元素个数 |
| `size` | 每个元素占用的字节数 |
| `compar` | 比较两个元素的回调函数 |

- 比较函数收到的是**两个元素的地址**，不是元素值。
- qsort 对比较函数的返回值要求如下：
    - 返回负数：第一个参数排在第二个参数前面。
    - 返回 0：两个参数视为相等（不改变相对顺序）。
    - 返回正数：第一个参数排在第二个参数后面。

```c
#include <stdio.h>
#include <stdlib.h>

int cmp(const void *pa, const void *pb) {
    return *(int*)pa-*(int*)pb; //升序
}

int main() {
    int a[] = {5, 3, 1, 2, 4};
    size_t n = sizeof(a) / sizeof(a[0]);
    qsort(a, n, sizeof(a[0]), cmp);
    
}
```

- 改成 `return *(int*)b-*(int*)a;` 就是降序。
