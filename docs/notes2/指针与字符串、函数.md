# 第九讲
## const
1. const限定关键字与指针变量
2. const不宜出现在类型和*之间
3. double x[const] 等价于 double * const x
4. const double x[const] 等价于 const double * x / double const *x
```c
#include<stdio.h>
int main(){
    int *p1 = 0;
    const int *a = p1;
    p1 = a;// 错误：舍弃限定符（const int 到 int）
    p1 = (int *)a;
}
```
## 字符串字面量
1. 字符串字面量
```c
char *s = "STUDENT";
//"STUDENT"只读
char t[] = "STUDENT";
//先开辟t[8]，然后初始化，memcpy(t,(char*){"STUDENT"},8);
*t = 'T';//正确，t指向的是另外的内存
*s = 'T';//错误：段错误，s指向的是不可更改的内存
```
2. 字符串字面量数组
```c
char *ss[] = {"hello","hello","!"};
char ** pp = ss;
//*ss[]指向只读字面量
char sa[][10] = {"hello","hello","!"};
//sa[M][N]是连续的数组，sa是可以更改的
```

## void指针
void*仅保存指针的值（地址值），而忽略了指向数据的类型，因此编译器不允许使用“ * ”解引用运算、下标运算  
（不知道往后读多少位）
- 作为任意类型数据的指针，任意类型指针都可以隐式转为void*
- void*类型的变量可超越指针兼容性，隐式转为任意类型指针  

在stdlib.h中声明了两个函数  
`  
 void* malloc(size_t size);  `  
 `
 void free(void * ptr);  
 `  
malloc和free必须成对存在
## 函数指针
函数名称就是一个指针  
函数返回值类型(* 指针变量名)(函数参数类型列表)  
如: `int (*p)(int,int);`    
函数指针变量没有算术运算，也没有下标运算
```c
int Func(int x);
int (*p)(int x);
p = Func;
int a=1;
int c=(*p)(a);
```
回调函数，函数指针作为某个函数的参数，由外部函数逻辑来决定函数行为
