## 数组的基本概念

- **数组**：把若干个**相同类型**的元素放在一块连续的内存中。
- **元素类型**和**元素个数**共同决定数组类型，例如 `int a[5]` 是含 5 个 `int` 的数组。
- **下标**从 `0` 开始。长度为 `n` 的数组，有效下标是 `0 ~ n-1`。
- 元素的地址按以下规律计算：`首元素地址 + 下标 × sizeof(元素类型)`，这里的偏移以字节为单位。

## 一维数组的定义

**基本格式：** `类型说明符 数组名[整数常量表达式]`

```c
int a[5];        // 5 个 int 元素：a[0] ~ a[4]
double data[10]; // 10 个 double 元素
```

- 方括号里的数必须是常量，来开辟已知大小的内存。
- 数组定义后，长度不会自动增减；`a[5]` 已经越界。
- C 不会自动检查下标，越界读写属于**未定义行为**：可能会导致崩溃。

### 常量长度与变长数组

```c
#define N 5 //也可以用const int N = 5;
int a[N]; // 用整数常量表达式指定长度
```

- **变长数组（VLA）**：在程序运行时，用变量决定长度；创建后也不能自动改变大小。（其实一般不用）
- C99 引入 VLA，后续标准和不同编译器的支持情况有差异。
- 在 C11/C17 中，不能用 `{0}` 等初始化列表初始化 VLA，应使用循环逐个赋值。

```c
int n;
if (scanf("%d", &n) == 1 && n > 0 && n <= 100) {
    int a[n]; // 需要编译器支持 VLA；限制长度，避免占用过多空间
    a[0] = 1;
}
```


## 一维数组的初始化

```c
int a[5] = {0, 1, 2, 3, 4}; // 全部初始化
int b[5] = {1, 2};          // 实际为 {1, 2, 0, 0, 0}
int c[5] = {0};             // 全部初始化为 0
int d[] = {1, 2, 3};        // 自动推导长度为 3，不是可变长度数组
```

- 初始化列表短于数组长度时，**剩余元素自动补零**。
- 函数内未初始化的普通局部数组，元素值不确定。
- 全局数组和带 `static` 的数组，如果没有显式初始化，元素会自动置零。
- 初始值会转换成元素类型，例如 `int a[] = {1, 2, 3.14};` 中的第三个元素是 `3`，小数部分被舍去。

## 访问、修改与复制

### 下标访问

```c
int a[5] = {0};
a[2] = 10;      // 修改第三个元素
int x = a[2];   // 读取第三个元素

for (int i = 0; i < 5; i++) {
    printf("%d ", a[i]);
}

for (int i = 4; i >= 0; i--) {
    printf("%d ", a[i]); // 逆序输出
}
```

- 下标可以是整数表达式，如 `a[i + 1]`，`a[i * 3]`等。

### 数组不能整体赋值

```c
int a[3] = {1, 2, 3};
int b[3];

// a = {4, 5, 6}; // 错误：初始化列表不能用于定义后的整体赋值
// b = a;         // 错误：数组不能整体赋值

for (int i = 0; i < 3; i++) {
    b[i] = a[i]; // 逐个复制元素
}
```

- 大多数情况下，数组名就是首元素的地址。`a[i]` 则可以赋值。

### 左值和右值

![](https://github.sysumsc.cn/https://raw.githubusercontent.com/Seanoll/imagebed/main/20261102120116032.png)

- 左值：可放置在赋值运算符左侧的值，具有持久存储位置的对象
- 右值：不具有固定存储位置的临时值，表达式求值后立即销毁

## 数组的输入输出

- `int`、`float`、`double` 等数组通常用循环逐个输入、输出。`char`数组可以整个输入输出。
- 输入一个数组元素时要传它的地址，如 `scanf("%d", &a[i])`。

### 先输入个数

```c
int count, arr[100];
scanf("%d",&count);

for (int i=0; i<count; i++) {
    scanf("%d",&arr[i]);
}
```

### 用特殊值结束

```c
int arr[MAX_LEN];
int count = 0;
const int SPEC = -1;

do {
    scanf("%d",&arr[count++]);
} while (arr[count-1]!=SPEC);
count--; 
```

- `-1` 是**结束标记**，不计入有效数据，所以在最后让数量减一。

### 用文件结束标志结束

```c
#include<stdlib.h>
// …
int count = 0;
while (scanf("%d",&arr[count++])!=EOF);
count--;
```

- `scanf` 的返回值：
  - 正整数：表示成功按指定格式读取并赋值的变量个数。
  - 0：表示输入与格式不匹配，无法正确读取任何值。
  - EOF（-1）：表示输入流结束或发生错误。
- 从文件读取到末尾时会遇到 `EOF`。Windows 控制台通常用 `Ctrl+Z` 后回车表示输入结束。

## 数组长度与清零

### 用 sizeof 求元素个数

```c
int a[5] = {1, 2, 3, 4, 5};
size_t n = sizeof(a) / sizeof(a[0]);
printf("%zu\n", n); // 输出 5
```

```c
#define LEN_ARRAY(a) (sizeof(a) / sizeof((a)[0]))
```

- `sizeof(a)`：整个数组占用的字节数。
- `sizeof(a[0])`：单个元素占用的字节数。

> size_t是无符号整数，可能占4字节或8字节，int是有符号整数，一般占4字节，输出size_t类型用%zu。

### 清零

```c
#include <string.h>

int a[5];
memset(a, 0, sizeof(a));
```

- `memset(起始地址, 字节值, 字节数)` 按**字节**填充；我们只用来赋值0或-1。
- `memset(a, 1, sizeof(a))` **不是**把每个整数置为 1。要给每个元素赋 1，应使用循环。

## 二维数组

### 定义与访问

```c
int mat[3][4]; // 3 行、4 列，共 12 个 int 元素
mat[1][2] = 6; // 第 2 行、第 3 列
```

- 二维数组可以理解成“**每个元素都是一行数组的数组**”。两个下标分别表示行号和列号，都从 `0` 开始。

### 存储顺序

- C 的二维数组按**行优先**连续存储：先存第 0 行，再存第 1 行。（指的是地址）
- 图中的行列是逻辑关系，实际内存仍然是一段连续空间。

### 初始化

```c
int a[2][3] = {{1, 2, 3}, {4, 5, 6}}; // 分行初始化，推荐
int b[2][3] = {1, 2, 3, 4, 5, 6};     // 按行顺序依次填入
int c[2][3] = {{1}, {4, 5}};          // {{1, 0, 0}, {4, 5, 0}}
int d[2][3] = {0};                    // 全部置零
int e[][3] = {{1, 2}, {4}};           // 推导为 2 行，每行仍有 3 列
```

- 未给出的元素自动补零。
- 用初始值推导长度时，可以省略第一维，其他维度不能省略，否则无法确定每行大小。
- 更高维数组按同样思路理解：数组的元素仍然可以是数组。

### 遍历与长度

```c
int mat[2][3] = {{1, 2, 3}, {4, 5, 6}};
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", mat[i][j]);
    }
    printf("\n");
}
```

- 行数：`sizeof(mat) / sizeof(mat[0])`。
- 列数：`sizeof(mat[0]) / sizeof(mat[0][0])`。
- 总元素个数：`sizeof(mat) / sizeof(mat[0][0])`。
