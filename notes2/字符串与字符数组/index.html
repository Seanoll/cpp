    字符串与字符数组

    字符类型与字符常量

    • char 是一种整数类型，占 1 字节；C 保证每字节至少 8 位，常见平台是 8 位。
    • 字符以编码值存储，因此可以参与整数运算。常见 ASCII 编码：'A' = 65、'a' = 97、'0' = 48、空格 ' ' = 32。
    • char 是否带符号由实现决定，需要明确时使用 signed char 或 unsigned char。
    • 在 C 语言中，普通字符常量 'A' 的类型是 int，不是 char。
    char c = 'A';
printf("%c\n", c);       // 输出字符 A
printf("%d\n", c);       // ASCII 环境下输出编码值 65
printf("%c\n", 'A' + 1); // ASCII 环境下输出 B
printf("%zu %zu\n", sizeof(char), sizeof('A')); // 1 和 sizeof(int)

    转义字符

    写法 含义
    \0 编码值为 0 的空字符，用作字符串结束符
    \n 换行
    \t 水平制表符
    \r 回车
    \\ 反斜杠
    \' 单引号
    \" 双引号
    \? 问号
    \a 警报
    \b 退格
    \f 换页
    \v 垂直制表符
    \ooo 1～3 位八进制数字表示的字符编码，如 \101
    \x... 一个或多个十六进制数字表示的字符编码，如 \x41
    \uXXXX、\UXXXXXXXX 分别用 4 位、8 位十六进制数字表示 Unicode 码点
    • ASCII 环境下，'\101'、'\x41' 都表示 'A'。
    • '\0' 是零值字符，'0' 是数字字符，二者不同。

    课件写法说明：课件将 \u... 简写为“UTF-16 或 UTF-32 编码”。它们更准确地说是 Unicode 码点的写法，不代表普通 char 数组就采用这两种编码，存储字节仍与字符类型和执行编码有关。

    字符串的基本概念

    • 字符串是字符序列。C 风格字符串以第一个 '\0' 作为结束标志。
    • 字符串长度不包含结束符；存储时还要为结束符多留 1 字节。
    • 空串是 ""，长度为 0，但仍要用 1 字节保存 \0；" " 含一个空格，长度为 1。
    • 字符集是允许使用的字符集合。若有 k 种字符，长度为 n 的字符序列共有 k^n 种。
    "Hello" 的存储：'H' 'e' 'l' 'l' 'o' '\0'
字符串长度：5
所需空间：6 字节

    字符、字符数组与字符串

    写法 含义
    'H' 一个字符常量，在 C 中类型为 int
    "H" 字符串字面量，包含 'H' 和 '\0'，共 2 字节
    char c = 'H'; 用一个 char 变量保存字符
    char a[3] = {'H', 'i', '!'}; 字符数组，没有结束符，不能直接作为字符串使用
    char s[] = "Hi!"; 可作为字符串使用的字符数组，共 4 字节
    • 字符数组只说明元素类型是 char，不保证有结束符。
    • 传给 %s、strlen 等字符串操作的内容，必须在可访问范围内存在 \0，否则可能越界读取。

    字符数组的初始化与修改

    char a[4] = {'H', 'i', '!', '\0'};
char b[4] = "Hi!";
char c[] = "Hi!"; // 自动推导为 4 字节，与前两种内容相同
char d[10] = "Hi!"; // 后面的元素都补零
char e[10] = {0};   // 初始为空串
    • 字符串字面量通常会自动带上结束符；目标数组必须留出空间。
    • 容量为 N 的字符数组，最多保存 N-1 字节的字符串内容。
    • C 允许 char s[3] = "Hi!"; 恰好只存三个可见字符，但它没有空间存 \0，不能作为字符串使用。
    char s[4];
// s = "Hi!"; // 错误：数组定义后不能整体赋值
s[0] = 'H';
s[1] = 'i';
s[2] = '!';
s[3] = '\0';
    • 也可以用后面的 strcpy 复制字符串。
    • char c = "H"; 错误：不能把字符串地址当作一个字符保存，应写 char c = 'H';。

    字面量与字符指针

    char s[] = "Hello";    // 数组里保存一份副本，可以修改元素
const char *p = "Hello"; // 指向字面量，按只读内容使用
s[0] = 'h';

    课件写法说明：课件写 char *greeting = "Hello";。C 中可以这样初始化，但不能通过它修改字符串字面量，修改属于未定义行为。建议写 const char *greeting；需要修改内容时用字符数组。

    长字符串与换行

    char s[] = "Hello, "
           "world!\n";
    • 相邻的字符串字面量在编译时自动拼接，结果是 "Hello, world!\n"，中间不会额外插入结束符。
    • 源代码行末的反斜杠 \ 紧接换行，可把两行接成一行；不会给字符串插入换行。
    • 字符串中需要换行，应写 \n。较长字面量优先用上面的相邻拼接写法。

    中途出现结束符

    char s[] = "Hi\0there";
printf("%s\n", s);       // 只输出 Hi
printf("%zu\n", strlen(s)); // 2，需要 <string.h>
    • 数组里可以在 \0 后继续存数据，但字符串操作只处理第一个 \0 之前的部分。
    • 中文等字符可能由多个字节编码。strlen 数的是字节数，不一定是文字个数；例如 UTF-8 下一个常见汉字通常占 3 字节。

    字符串输入输出

    以下函数需要 #include <stdio.h>。

    输出：printf 与 puts

    char s[] = "Hello";
printf("%s\n", s); // 按格式输出
puts(s);           // 输出字符串，并自动补一个换行
    • %s 和 puts 都在第一个 \0 处停止，不输出结束符本身。
    • 没有结束符的字符数组，应按已知长度逐个用 %c 或 putchar 输出。
    • 数字数组不能用 %s 整体输出，仍要逐个输出元素。

    输入单词：scanf

    char s[10];
if (scanf("%9s", s) == 1) {
    printf("%s\n", s);
}
    • %s 跳过开头的空白，读取到下一个空白字符时停止，不能完整读取带空格的一行。
    • 成功读取后，自动在末尾添加 \0。
    • %9s 最多读入 9 字节，给第 10 字节留出结束符空间。
    • 这里写 s，不是 &s；s 会转换为首字符的地址。
    • %c 读取单个字符时要传地址，例如 scanf("%c", &c)；它不会自动跳过空白，也不追加结束符。

    课件写法说明：课件使用 scanf("%s", str)。该写法没有长度限制，输入过长会越界；应按数组容量设置字段宽度，如容量为 10 时写 %9s。超出宽度的输入仍留在输入流中。

    输入整行：gets 与 fgets

    • 课件中的 gets(str) 可以读取包含空格的一行，去掉换行并补 \0。
    • gets 无法指定容量，已经从 C11 标准中删除，不应在新程序中使用。
    • 使用 fgets 指定容量：
    #include <stdio.h>
#include <string.h>

char s[100];
if (fgets(s, sizeof(s), stdin) != NULL) {
    s[strcspn(s, "\n")] = '\0'; // 如果读到了换行，就把它换成结束符
    puts(s);
}
    • fgets(s, N, stdin) 最多读入 N-1 个字符，成功时自动补 \0。
    • 如果容量足够，会连换行一起读入；上面的 strcspn 找到换行位置，没有换行时返回字符串长度。
    • 一行过长时只能读入前一部分，剩余内容留给后续读取。
    • 混用 scanf 和 fgets 时，注意 scanf 常把换行留在输入流中，紧接着的 fgets 可能只读到这一个换行。

    课件写法说明：保留 gets/puts 的整行操作知识点，实际输入改用有容量限制的 fgets。puts 是标准函数，可以继续使用；它与 printf("%s", s) 的区别之一是自动补换行。

    字符串处理函数

    下面的标准字符串函数需要 #include <string.h>。目标数组必须可写，容量必须足够。

    长度：strlen

    char s[20] = "Hello";
printf("%zu\n", strlen(s)); // 5，首个 '\0' 前的字节数
printf("%zu\n", sizeof(s)); // 20，整个数组的字节数
    • strlen 返回 size_t，不计算结束符。
    • sizeof("Hello") 是 6，因为字符串字面量的数组空间包括末尾 \0。
    • sizeof(p) 对字符指针求的是指针自身大小，不能代替 strlen(p)。

    连接：strcat 与 strncat

    函数 作用 返回值
    strcat(dst, src) 从 dst 的结束符位置开始追加整个 src，再写入结束符 dst
    strncat(dst, src, n) 最多追加 src 的前 n 个非零字符，再写入结束符 dst 
    char s[20] = "Hello";
strcat(s, " ");
strncat(s, "world!", 5); // s 为 "Hello world"
    • dst 原本就必须是合法字符串，不能把未初始化数组直接传给连接函数。
    • strcat 要求容量至少是 strlen(dst) + strlen(src) + 1。
    • strncat 的 n 是最多追加多少个字符，不是目标数组容量；所需容量至少为 strlen(dst) + min(n, strlen(src)) + 1。
    • 两者都不会自动检查目标容量，也不能用于源、目标内容重叠的情况。

    复制：strcpy 与 strncpy

    函数 作用 注意
    strcpy(dst, src) 覆盖目标内容，连同 src 的 \0 一起复制 容量至少为 strlen(src) + 1
    strncpy(dst, src, n) 最多从源复制 n 个字符；源不足 n 时把剩余位置补零 源长度大于等于 n 时不自动补结束符 
    char s[10];
strcpy(s, "Hi!");

strncpy(s, "Hello world", sizeof(s) - 1);
s[sizeof(s) - 1] = '\0'; // 手动保证结束符；结果截断为 "Hello wor"
    • strcpy 和 strncpy 返回 dst，源与目标不能重叠。
    • strncpy 的 n 不能超过目标容量，不能仅凭函数名带 n 就认为安全。

    课件写法说明：课件说 strncpy“不添加零值字符”，只适用于源长度大于等于 n 的情况；源较短时会补零。另外，课件向 char str1[15] 复制 "You are a student."，该字面量连结束符需要 19 字节，会越界，应扩大数组或明确截断。

    比较：strcmp 与 strncmp

    • 比较字符串内容不能用 ==；对两个字符串地址使用 == 比较的是地址。
    • strcmp(a, b) 从头逐字节比较，在第一对不同字符处决定大小，按 unsigned char 值比较。
    • 如果一个字符串是另一个的完整前缀，较短者更小；不是单纯按长度比较。
    • strncmp(a, b, n) 最多比较前 n 个字符，遇到结束符也会停止。
    返回值 含义
    < 0 a 小于 b
    == 0 比较范围内相同
    > 0 a 大于 b 
    strcmp("Hell", "Hello");    // < 0
strcmp("same", "same");     // == 0
strcmp("ABcD", "ABCD");     // ASCII 环境下 > 0
strncmp("abcX", "abcY", 3); // == 0，只比较前三个字符
    • 返回值只保证正、零、负，不保证恰好是 1 或 -1。

    查找：strchr 与 strstr

    函数 作用 找不到时
    strchr(s, c) 找字符 c 第一次出现的位置 返回 NULL
    strstr(s, sub) 找子串 sub 第一次出现的位置 返回 NULL 
    char s[] = "abcdedcbaf";
char *p = strchr(s, 'd');
if (p != NULL) {
    printf("%td\n", p - s); // 3：位置指针减首地址，得到下标
    printf("%s\n", p);     // dedcbaf：从找到的位置输出到结束符
}

char *q = strstr(s, "ded");
if (q != NULL) {
    printf("%td\n", q - s); // 3
}
    • 找到后返回的指针指向原字符串内部，不会自动复制出新字符串。
    • strchr(s, '\0') 能找到结束符；strstr(s, "") 返回 s。

    课件写法说明：课件直接计算 strchr(...) - str 或用 %s 输出查找结果。应先判断是否为 NULL，否则“没找到”时会出错。指针差的类型是 ptrdiff_t，对应输出格式为 %td，不是课件中的 %d。

    大小写转换：strlwr 与 strupr

    • 课件的 strlwr(s)、strupr(s) 分别把字符串中的字母转为小写、大写，但它们不是标准 C 函数，部分编译器才提供，也可能使用不同名称。
    • 标准 C 使用 <ctype.h> 中的 tolower、toupper，逐字符转换：
    #include <ctype.h>

char s[] = "Hello";
for (size_t i = 0; s[i] != '\0'; i++) {
    s[i] = (char)tolower((unsigned char)s[i]);
}
// 需要大写时，将 tolower 改为 toupper
    • 转成 unsigned char 后再传入，避免负的 char 值导致未定义行为。
    • 这是逐字节字符处理，不是通用的 Unicode 文字大小写转换。

    课件写法说明：保留 strlwr/strupr 的作用说明，实际编写可移植的 C 程序时采用标准库的逐字符转换方式。
