    结构体、共用体和枚举类型

    结构体

    使用关键字 struct 完成类型定义等操作： 1. 定义结构体类型与变量。"struct identifier { 成员变量表 }" 完成结构体定义。然后直接定义该类型的实例变量，注意 ";" 结束。 2. 仅定义结构体类型变量。注意：C语言中，结构体类型是 "struct STUDENT"，不是 " STUDENT "，与C++不同。 3. 仅定义结构体类型。以后再声明它的实例变量。注意：定义格式 "struct identifier { members_list } vars_list ;"，"}" 后分号不能省。 4. 习惯上 struct 标识符 用大写风格 

    struct STUDENT {
    char id[6];
    char name[10];
    int age;
    struct ADDRESS *home;
} john;
struct STUDENT anna;
struct ADDRESS {
    char area_id[6];
    … …
};

    结构体的定义

    （1）先定义结构体类型再定义变量名 

    struct student
{
    long studentID;
    char studentName[10];
    char studentSex;
    int yearOfBirth;
    int score[4];
};
struct student stu1;
    （2）在定义结构体类型的同时定义变量 
    struct student
{
    long studentID;
    char studentName[10];
    char studentSex;
    int yearOfBirth;
    int score[4];
} stu1;
    （3）直接定义结构体变量（不指定结构体标签，不能单独进行声明） 
    struct
{
    long studentID;
    char studentName[10];
    char studentSex;
    int yearOfBirth;
    int score[4];
} stu1;
    - 结构体不支持VLA - A 结构体中如果包含 B 结构体类型（非指针）成员，则 B 结构体必须在 A 之前定义 
    struct stu{
    struct add home;
    char name[10];
    int num[10];
};
struct add{
    char area[6];
    int mail[6];
};
    这会报错"[Error] 'add' does not name a type" 但是如果在stu中定义add *home时不会报错，因为当使用结构体时，编译器需要知道所有信息来确定内存大小，而指针不需要知道所有信息
    注意：C语言中定义结构体时必须加struct，C++中不需要加strcut！！

    typedef

    1. 关键字 typedef 可以为类型起一个新的别名𝑡𝑦𝑝𝑒𝑑𝑒𝑓 𝑜𝑙𝑑𝑁𝑎𝑚𝑒 𝑛𝑒𝑤𝑇𝑦𝑝𝑒𝑁𝑎𝑚𝑒;
    2. 定义结构体 
      typedef struct {
    char id[6];
    char name[10];
    int age;
} Student;

Student anna, john, *person;
      使用typedef可以把结构体从变量变成类型，定义结构体时不需要再加struct
    3. 定义数组或指针 
      typedef int MATRIX_3[3][3];//把3*3的二维数组别名叫做MATRIX

MATRIX_3 a, b = {{1},{4,5},{7,8,9}};

typedef int (*CMP_F)(int, int);//把返回值为int，参数为int,int的函数别名叫做CMP_F
typedef int (*PTR_3)[3];//把指向一维数组（数组长度为3）的行指针叫做PTR_3

void mysort(int *base, int n, CMP_F f);
PTR_3 p1, p2, p3, *p;

    结构体操作

    1. 初始化 
      typedef struct {
    int year, month, day;
} Date;

typedef struct {
    char id[6];
    char name[10];
    Date birthday;
    int age;
} Student;

Student anna = {"0101", "anna", {1995,10,1}};
    2. 地址
      结构体的实例变量，成员变量都可以使用 取地址、解引用和赋值运算。其中实例变量赋值一次可复制所有成员的值，包括其中的数组类型成员。结构体第一个成员的地址值，一定等于该成员所属实例变量的地址值
    3. 成员运算符
      指针才能用->，结构体实例不能用->！！ 
      anna.birthday.year = 1995;//实例变量用原点成员运算符
person-> birthday.year = 1995;//指针变量用指针成员运算符
(*person).birthday.year = 1995;//注意：原点运算符优先级高于解引用，括号不能省
      注意：(void*)&anna == (void*)anna.id 是地址相等，但 &anna 和 anna.id 是 不同类型指针。例如：scanf("%s", anna.id); 不能写成 scanf("%s", &anna);
      anna是student*类型，而&anna.id是char*类型

    共用体

    • 与结构体一样，共用体(union)也是一种派生数据类型。共用体的成员共享同一个存储空间。共用体的成员可以是任意数据类型。
    • 声明一个共用体与声明一个结构体的格 式相同，只不过是将关键词 struct 改为 union。右边这个共用体定义表示number 是一个共用体类型，它的成员是 整型变量x 或者 双精度型变量y 
      union number{
    int x;
    double y;
};
      注意：实例变量地址值和所有成员变量地址值都相等。不能用运算符==或!=来比较两个结构体/共用体。共用体不能作函数参数。

    枚举类型

    enum DAY
{
      MON=1, TUE, WED, THU, FRI, SAT, SUN
}day;

int main()
{
    // 遍历枚举元素
    for (day = MON; day <= SUN; day++) {
        printf("枚举元素：%d \n", day);
    }
}
